## 目标

一个参数化的复数混频器：把基带复数 `(i_in + j·q_in)` 乘上复本振 `e^{±jφ}`。

```
                 ┌──────────────┐
  i_in ─────────►│              ├─────► i_out
  q_in ─────────►│    mixer     │
 cos_in ────────►│              ├─────► q_out
 sin_in ────────►└──────────────┘
```

| 参数 | 含义 | 默认 |
|---|---|---|
| `IW` | 输入 i/q 位宽（补码） | 12 |
| `AW` | 本振 cos/sin 位宽（补码） | 12 |
| `OW` | 输出 i/q 位宽（补码） | 13 |
| `SHIFT` | 输出右移位数（**增益归一化**，见下） | `AW-1` |
| `ROUND` | 1 = 四舍五入；0 = 直接截断 | 1 |
| `CONJ` | 0 = 上变频 `e^{+jφ}`；1 = 下变频 `e^{-jφ}` | 0 |

| 端口 | 方向 | 含义 |
|---|---|---|
| `clk` / `rst_n` | in | 时钟 / 低有效异步复位 |
| `i_in` / `q_in` | in | 输入基带复数（补码） |
| `cos_in` / `sin_in` | in | 复本振（补码，由 `nco.v` 给） |
| `i_out` / `q_out` | out | 混频后的复数（补码，**晚 1 拍**） |

运算（**这张表就是接口约定，写死**）：

| | `CONJ=0` 上变频（DUC 用） | `CONJ=1` 下变频（DDC 用） |
|---|---|---|
| `i_out` | `i·cos − q·sin` | `i·cos + q·sin` |
| `q_out` | `i·sin + q·cos` | `q·cos − i·sin` |

⚠️ 下变频时**两路都要翻符号** —— 只翻 q 路得到的东西既不是上变频也不是下变频。
第一版就是这么写错的，而且 Python 参考模型犯了同一个错，向量回放全绿。
详见 [学习备忘](../docs/学习备忘.md) 第 10 节。

## 验收标准

- [x] 复位后输出为 0；复位期间输入拉满也还是 0；**运行中途异步复位**不等时钟沿立刻清零
- [x] **延迟 1 拍**：输入变了但时钟沿没来，输出保持上一拍的值（没有组合直通）
- [x] **上/下变频方向正确**：手算边界用例
      （`cos=0, sin=64, i=q=64` → 下变频 `i_out=+64, q_out=−64`；
        本振 +90° 时输入 `(2047,0)` → 输出 `(0,+2046)`）
- [x] **四舍五入 / 截断可区分**：同一个输入，`ROUND=1` 与 `ROUND=0` 的两个实例
      在 1620 个用例里有 **944 个结果不同**；tie 点手算对账
      （1024→1 vs 0；−1024→0 vs −1；1023→0 vs 0；3072→2 vs 1）
- [x] **饱和而不是回绕**：`OW=8` 的实例上，正溢出钳到 `+127`、负溢出钳到 `−128`
- [x] **参数真的起作用**：`IW/AW/OW/SHIFT/CONJ` 换了 4 组配置各自全对
- [x] **幅度保持**（性质断言）：单位幅度本振扫 32 个相位点，
      输出 `i²+q²` 与输入的偏差 ≤ 8 LSB（尺度错 2 倍会差 ≈1024 LSB，所以这条有牙齿）
- [x] `make sim` 全绿、`make lint` 无警告
- [x] **上板 + ILA**（2026-10-17）：`i_out` 周期 = **1000 个采样点**（50 kHz），
      `sig_sin` = **200 个点**（250 kHz），比例 **5:1**；把顶层 `CONJ` 改 0 又验了
      和频 **450 kHz**（约 73 个周期/窗口）。两版都符合 1/(FREQ_IN∓FREQ_LO)。

## 写之前要决定的三件事（已决定 + 理由）

**① 输入信号从哪来**

混频器的输入是"基带 I/Q"，s02 阶段还没有调制器。板级顶层 `mixer_top.v` 用**第二个 NCO**
造一个复单音当输入（`I=cos, Q=sin`，即 `e^{jω_in t}`），本振用第一个 NCO。

- 好处：板子上立刻有东西可混，ILA 上的判据是**频率**（输入 250 kHz、本振 200 kHz
  → 输出 50 kHz），一眼能核，不依赖任何外部数据源。
- 代价：`mixer_top.v` 里那个 NCO 是**实验台器材，不是 DUC 的一部分**；
  真正的 DUC 里这一侧接成型滤波之后的符号（s03/s04 之后才有）。
  所以本 stage 的算法本体只有 `mixer.v` 一个模块，顶层不被 s05 复用。

**② 位宽与增益（这一条最容易出事）**

- 全精度和是 `IW+AW+1` 位。`IW=AW=12` 时是 25 位
  （`(-2048)×(-2048)×2 = 2^23`，24 位补码最大只到 `2^23−1`，所以确实需要第 25 位）。
  **先按全精度算，最后才截** —— 提前截中间结果多丢精度，还省不下乘法器。
- 定点数相乘会把尺度"平方"：`1.0` 从 `2^(W−1)` 变成 `2^(2W−2)`。
  所以 `SHIFT = AW−1` 把尺度除回去，本振幅度 1.0 时**混频不改变信号尺度**（单位增益）。
  - `SHIFT` 取小了 → 输出整体放大，容易饱和削顶；
  - `SHIFT` 取大了 → 输出整体变小，白白丢低位精度。
- 输出位宽 `OW = IW+1` 对"单位增益 + 复数混频"是**刚好够**的：
  `|i·cos ± q·sin| ≤ 2^(IW−1)·2^AW`，右移 `AW−1` 位后 ≤ `2^IW`，
  而 `OW = IW+1` 位补码能到 `2^IW−1`……
  **实测**：只有 `i=q=cos=sin=−2048`（NCO 永远给不出的角）时才会顶到 4096 越界 1 个 LSB，
  向量里那 1~2 个饱和用例就来自它。真实 NCO 输出限幅在 ±2047，
  所以顶层 `OW=13` **永远不会饱和**。

**③ 舍入还是截断，溢出怎么办**

- 右移是"向 −∞ 取整"，会给输出带来约 −0.5 LSB 的**直流偏置**。
  `ROUND=1` 先加半个 LSB 再移，变成四舍五入（tie 一律向 +∞），偏置基本消掉，代价一个加法器。
- 加半个 LSB 之后最大正值可能**刚好越过上界**，所以：
  先把和**加宽 1 位**再舍入，最后**饱和**到 `OW`。
  回绕会把"最大的正数"变成"最大的负数"，波形上就是削顶处突然翻符号 ——
  定点设计里最经典的一类事故，`M2` 那次反向验证就是把它改回回绕。

## 这个 stage 的验证方法（值得记住的一套）

RTL 的算术用肉眼看不出来，而在 testbench 里用 Verilog 再写一遍同样的算术，
两边很可能犯**同一个**理解错误 —— 那就成了自己证明自己。所以这里的证据分三层：

| 层 | 手段 | 抓什么 |
|---|---|---|
| ① 参考模型 + 向量回放 | `scripts/gen_mixer_vec.py`（Python，任意精度整数）算期望值落到 `vec/*.txt`，TB 逐拍回放比对 | 位宽、符号扩展、舍入、饱和的实现错 |
| ② 性质断言 | 单位幅度本振下 `i²+q²` 不变、峰值处 q≈0、零输入出零 | "整体尺度错 2 倍"这类错，换参数也成立 |
| ③ 边界手算 | 把期望值直接写在断言里，人能一眼核对 | tie、±饱和、`CONJ` 方向 |

**三层里任何一层单独都不够。** 这次就是 ①③ 一起才说明问题：
① 全绿（因为参考模型和 RTL 错得一样），③ 把真 bug 揪出来了。

向量文件格式见 `vec/README.md`。
