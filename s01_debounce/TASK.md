# Stage 1.3 — 按键消抖

## 目标

机械按键在按下和松开的瞬间会产生几毫秒的抖动（电平快速跳变）。
做一个消抖模块，输出干净的电平，并且给出"按下""松开"的脉冲。

## 要求

| 参数 / 端口 | 含义 |
|---|---|
| `CLK_HZ` | 输入时钟频率 |
| `DEBOUNCE_MS` | 需要稳定多久才算有效（典型 10~20 ms） |
| `key_in` | 原始按键输入（**异步，必须先同步**） |
| `key_level` | 消抖后的电平 |
| `key_press` | 按下脉冲（1 拍） |
| `key_release` | 松开脉冲（1 拍） |

## 验收标准

- [ ] `key_in` 抖动期间 `key_level` **保持不变**
- [ ] `key_in` 稳定超过 `DEBOUNCE_MS` 后 `key_level` 才翻转
- [ ] 一次完整按下 + 松开只各产生**一个**脉冲
- [ ] 抖动期间不产生任何脉冲
- [ ] 复位后 `key_level` 有确定的初值
- [ ] testbench 里**注入随机抖动**（不能只测理想情况）
- [ ] `make lint` 无警告

## 提示

- **第一步永远是同步**：`key_in` 是异步的，先过 `rtl/common/sync_2ff.v`。
  不做这一步，后面全是玄学 bug。
- 消抖的核心就是一个计数器：如果输入和当前输出电平不同，计数器累加；
  累加到阈值就翻转输出并把计数器清零；如果中途输入又变回去了，计数器清零。
- 两个脉冲直接接 `rtl/common/edge_detect.v` 的输出即可。
- testbench 里制造抖动：用 `$random` 或者手写一段
  `key_in` 在 1~3 个时钟周期内随机翻转的序列。
  **只测理想波形是测不出 bug 的** —— 这是这个任务真正想教的东西。
