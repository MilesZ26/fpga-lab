# Stage 1.4 — UART 收发（重点）

## 为什么这是 Stage 1 的重点

UART 看起来简单，但它是你**后面所有调试的眼睛**：
没有串口输出，你在板子上就只能靠 LED 猜；有了串口，
你可以把内部信号、状态机状态、计数值直接打出来。

而且它是你第一个真正的**接口**：
帧格式、采样时机、跨时钟域、错误处理，后面 SPI / I2C / AXI 要面对的问题它都有。
所以**值得在这个上面多花时间**。

## 要求

| 参数 / 端口 | 含义 |
|---|---|
| `CLK_HZ` | 输入时钟频率 |
| `BAUD` | 波特率，例如 115200 |
| 帧格式 | 8 数据位、无校验、1 停止位（**8N1**），LSB 先发 |
| `tx_data[7:0]` / `tx_start` / `tx_busy` / `tx` | 发送 |
| `rx` / `rx_data[7:0]` / `rx_valid` | 接收 |

分成两个独立模块：`uart_tx.v` 和 `uart_rx.v`（方便单独测和单独复用）。

## 验收标准

- [ ] **TX**：输出的位时序符合 8N1，波特率误差 < 2%
- [ ] **RX**：能从模拟的串口波形中恢复出正确字节
- [ ] **回环**：`uart_tx` 的输出接到 `uart_rx` 的输入，
      任意字节序列（含 0x00、0xFF）都能原样恢复
- [ ] **波特率容限**：给 RX 输入偏 ±3% 的位宽，验证仍能正确接收
- [ ] **异常**：RX 遇到中途拉高的起始位（假起始）不挂死，能回到空闲态
- [ ] `tx_busy` 在发送期间拉高，发送结束后拉低
- [ ] `make lint` 无警告

## 提示

**必须踩对的几个点：**

1. **采样要在位的中间，不是边界。**
   计数到 `BAUD_DIV/2` 时采样，此时离两边沿最远，最安全。
2. **起始位检测要过 `sync_2ff`。**
   `rx` 是从外部进来的异步信号，不过同步器就是在赌运气。
3. **起始位要二次确认。**
   检测到下降沿后，等到位中间再采一次确认还是低电平，
   否则一个毛刺就会被当成起始位（假起始）。
4. **`BAUD_DIV = CLK_HZ / BAUD`。**
   注意 115200 在 50 MHz 下算不尽（434.03），
   取整会带来误差 —— 这正是要验证"误差 < 2%"的原因。
5. RX 的采样时钟和 TX 的比特时钟是**各自独立**的，
   接收端每个字节都靠起始位重新对齐（这叫"异步"串口）。

## 建议顺序

1. 先写 `uart_tx` + testbench（只测输出波形对不对）
2. 再写 `uart_rx` + testbench（喂它一段模拟波形）
3. 最后做回环测试
