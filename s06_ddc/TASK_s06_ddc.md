# Stage 6 — DDC（抽取 + 下变频 + 基带 FIR）

> 基带数据通路的第六个 stage，也是 s05 的严格逆过程：
> **2× 抽取 → 复数混频（下变频）→ 基带 FIR**。s05 把单音搬上去，s06 把它搬回来。
>
> 这个 stage 的核心不是"再写一遍 FIR"，而是**回环**：DUC 和 DDC 串起来之后，
> 输出还是不是原来那个 0.01 Fs 的复单音？幅度、频率、相位、位宽，只要有一处错，
> 回环就会出现"频率对但相位歪"或"幅度对但星座转"的现象。
>
> **这一轮最有价值的一课：同一个 DDC 核，接在不同位置要用不同的 LO_DLY。**
> 独立 DDC 是 14，回环是 23。差的那 9 拍就是 DUC 的延迟。

## 目标

```
  i_e/i_o/q_e/q_o (15b) ──► decim2_I / decim2_Q ──► 16b
                                                      │
                                          ┌───────────▼───────────┐
                                          │ mixer CONJ=1          │──► 17b
                                          │ NCO @ f_lo, LO_DLY=14/23 │
                                          └───────────┬───────────┘
                                                      │
                                          ┌───────────▼───────────┐
                                          │ FIR_I / FIR_Q (47 抽头)│──► 18b
                                          └───────────┬───────────┘
                                                      │ 饱和到 13 位
                                                      ▼
                                                  i_out / q_out (13b)
```

| 参数 | 含义 | 默认 |
|---|---|---|
| `IW` | 输入位宽（= DUC 的 `OW_INT`） | 15 |
| `CW` / `N_DEC` | 半带系数位宽 / 总抽头数 | 16 / 61 |
| `N_FIR` | 信道 FIR 抽头数 | 47 |
| `AW` / `FREQ_HZ` | NCO 幅度 / 本振频率 | 12 / 2.5 MHz（0.05 Fs） |
| `OW_DEC` / `OW_MIX` / `OW_FIR` | 各级输出位宽 | 16 / 17 / 18 |
| `OW_OUT` | 最终输出位宽 | 13 |
| `SHIFT_DEC` / `SHIFT_MIX` / `SHIFT_FIR` | 各级右移 | 15 / 11 / 15 |
| `LO_DLY` | 本振延迟 | **14（独立 DDC）/ 23（回环）** |

## 写之前要决定的四件事

### ① 为什么顺序是"抽取 → 下变频 → 基带 FIR"

s05 的顺序是"成型 FIR → 上变频 → 插值"，所以 s06 反过来：
"抽取 → 下变频 → 信道 FIR"。

- **先抽取**：ADC 在 2Fs 上给两相，先降到 Fs，后面所有运算都在低速率上做，省资源。
  半带滤波器本身就是抗混叠滤波器（s04 已经逐位验过）。
- **再下变频**：把低 IF（0.05 Fs）搬回 0。
- **最后信道滤波**：在基带上做低通，滤掉混频产生的高频分量和带外噪声。
  这一步在**基带**做，滤波器响应才是设计时看到的那条低通曲线。

> 旧 s03 TASK 只写了"DDC 里顺序反过来"，没说清反成什么样。
> s06 把顺序钉死：**decim → mixer → FIR**，并用回环向量逐位验证。

### ② 位宽链：反过来接，但不能"截回去"

```
DUC 输出 15
   │ decim2 (IW=15, OW=16, SHIFT=15)
   ▼
dec_i/dec_q 16
   │ mixer (IW=16, AW=12, OW=17, SHIFT=11, CONJ=1)
   ▼
mix_i/mix_q 17
   │ fir (IW=17, OW=18, SHIFT=15)
   ▼
fir_i/fir_q 18
   │ 饱和到 OW_OUT=13
   ▼
i_out/q_out 13
```

- **每一级的 `OW` = 下一级的 `IW`**，中间不截位。如果 decim 出 16 位却按 15 位接，
  随机信号会慢慢累积误差，回环向量会红。
- 输出 13 位不是"必须 13"：DUC 的输入是 12 位，整条链单位增益，13 位多留 1 位余量。
  如果换增益 >1 的滤波器，这里要重新算，饱和会兜底（不回绕）。

### ③ 为什么 LO 延迟是 14（独立）/ 23（回环）

这是 s06 最重要的一课。

- DUC 混频器在样本 n 上乘 `lo[n]`；这个样本经过 interp / decim 后到 DDC 混频器。
- 功能模型里，DDC 抽取输出 `w[n]` 携带的载波相位是 **`lo[n-10]`**。
  ⚠️ **10 不是半带的群延迟 15，而是相位延迟**：群延迟描述"包络晚多少"，
  相位延迟描述"载波转了多少"；在 f_lo=0.05 Fs 这个窄带上两者不是同一个数。
- RTL 的 LO 延迟线长度 = **模型下标 10 + 4 = 14**。那个 +4 和 DUC 的
  `LO_DLY=4` 是**同一个**混频器 handoff 常数（DUC 模型下标 0 → RTL 4）。
- **回环时再加 DUC 的 9 拍**：独立 DDC 的输入在 t 拍就到，回环里 DUC 的输出
  比输入晚 9 拍才到 DDC，所以 DDC 的本振要再多等 9 拍：**14 + 9 = 23**。

判别方法（`tb_ddc_core` 的 step 场景）：DC 1000 混上去再混下来：

| LO 下标 | 输出 | 说明 |
|---|---|---|
| 10（RTL 14） | **+998 / 0** | 相位对 |
| 15（RTL 19） | 0 / +998 | 差 90° |
| 20（RTL 24） | −998 / 0 | 差 180° |

> 这就是为什么"改 LO_DLY 只旋转相位，不改频率"：
> 频率由 NCO 的 `PHI_INC` 决定，相位由 LO 延迟决定。
> 用 ILA 看频率是看不出来的，必须看 I/Q 的符号/相对相位，或者用逐位向量。

### ④ 为什么用同一张 `coef.mem` 和 `hb_odd.mem`

- DUC 的成型 FIR 和 DDC 的信道 FIR 都是 47 抽头低通，**同一张表**；
- DUC 的插值和 DDC 的抽取都是 61 抽头半带，**同一张表**。

好处：只有一份真值，改系数只要改一处；坏处：DUC/DDC 的滤波器是"同一个低通的
平方"，过渡带会变窄、通带纹波会翻倍。对 0.01 Fs 的单音无所谓；如果以后做
宽带信号，可能要换成 RRC + 匹配滤波，那是另一个设计。

## 延迟

| 量 | 值 | 组成 |
|---|---|---|
| DDC 输入 → 输出 | **10 拍** | decim 4 + mixer 1 + FIR 4 + **1 handoff** |
| DUC + DDC 回环 | **19 拍** | 9 + 10 |
| 回环冲激的第一个非零点 | 40..60（输出下标） | DUC FIR 23 + 半带 15×2 + DDC FIR 23 + 流水 |
| 回环 DC 稳态 | 998 | 两级混频增益 (2047/2048)² × 滤波器通带 ≈ 0.998 |

> **DDC 的 10 拍不是 9**：decim→mixer→FIR 之间各有一个 always 块的 handoff。
> 这个数是被 `tb_ddc_core` 的 `LAT=10` 钉死的；改流水级数要重标。
> 回环的 19 = 9 + 10，`tb_duc_ddc_loopback` 的 `LAT=19`。

| 改坏的地方 | 实际反应 |

判据（ILA 探针：`ie/io/qe/qo` + `di/dq`，共 86 位，建议深度 4096）：

| 检查 | 预期 | 说明 |
|---|---|---|
| LED0 | 常亮 | DDC 输出有持续活动（回环通了） |
| LED1 | 常亮 | DUC 输出有持续活动 |
| LED2/LED3 | 1 Hz 同闪 | 心跳 |
| `ie/qe` | 0.06 Fs（3 MHz，周期 ≈ 16.7 拍），幅度 ≈ 2040 | DUC 输出 |
| `io/qo` | 与 `ie/qe` 同频、错开**一个 2Fs 采样**（10 ns = 半个输入采样） | 插值两相 |
| `di/dq` | **0.01 Fs**（500 kHz，周期 100 拍），幅度 ≈ 2040 | 回环恢复到原频率 |
| `di` vs `dq` | 正交，幅度基本恒定 | 复单音 |
| 触发 | `ie[14]` 或 `di[12]` 的上升沿 | 别用 `== 峰值` |

排障顺序：
1. `ie/qe` 有且 0.06 Fs → DUC 侧对（和 s05 的判据一样）；
2. `di/dq` 完全没有 → 先查 `ddc_core` 的 `LO_DLY` 是不是 **23**（回环值），
   再查 `IW` 是不是 15（不能截回 12/13）；
3. `di/dq` 有但频率不对 → 查 `FREQ_LO` 和 DUC 是否一致；
4. `di/dq` 频率对但 I/Q 旋转/幅度不对 → 查 `CONJ=1`（两路都翻）、
   混频 `SHIFT=11`、LO 的 sin/cos 有没有接反；
5. LED0 不亮但 ILA 有 `di` → 活动计数器的阈值/位宽问题（`ACT_W=16`，
   约 0.8 ms 才点亮，属正常）。

> ⚠️ 回环是**数字**的（板上没有 ADC/DAC）：DUC 的并行四相直接接 DDC 的四相。
> 这不是"偷懒"——它正好把接口、位宽、相位、延迟全部串起来，而且 ILA 能同时
> 看到"搬上去"和"搬下来"两段。真正的 ADC/DAC 回环要等有模拟前端时再做。

## 这个 stage 的边界 / 留给后面

- **没有符号定时恢复 / 载波恢复**：回环用的是同一个 NCO（同源同相），
  所以 DDC 能直接下变频。真实接收机要有载波频偏/相偏估计和符号同步，
  那是通信算法的事，不在本 stage 里。
- **滤波器是"低通的平方"**：DUC/DDC 共用一张 `coef.mem`，过渡带变窄、
  通带纹波翻倍；宽带信号要换 RRC + 匹配滤波。
- **1:2 串并只在仿真里验过**：`deserializer2` 在 `rtl/common/`，
  `tb_serializer2.v` 逐拍验过；板上没有 ADC，所以 `ddc_top` 用的是并行四相。
- **没有 CIC**：2× 抽取用半带更省；要 8× 再考虑 CIC。
- **资源预估**：2 个 decim2（2×15 DSP）+ 1 个混频（4）+ 2 个 FIR（约 2×21）
  ≈ **76 DSP**；加上 DUC 的回环一共约 **152 DSP**（100T 有 240，够用）。
  实测以综合报告为准。
