## 半带表为什么只有 30 行

一个 **61 抽头**、截止恰好 1/4 采样率的线性相位低通，理想情况下：

```
h[30] = 0.5                  ← 中心抽头（不在表里，RTL 里写死 2^(CW-2)）
h[30±2k] = 0                 ← 偶数偏移全是 0（半带的定义）
h[30±(2k+1)] ≠ 0             ← 只有奇数偏移非零，共 30 个
```

所以表里只存 `h[1], h[3], ..., h[59]` 这 30 个数。RTL 再用对称性
（`o[i] == o[29-i]`）把它们折成 **15 个乘法器**。

| 项 | 约定 |
|---|---|
| 位宽 | `CW = 16` 位，二进制补码（`reg signed [15:0]`） |
| 每行 | 4 个十六进制字符（大写、前导零），一行一个数，无注释、无表头 |
| 顺序 | `o[0] = h[1]`（最外侧）→ `o[29] = h[59]`（最靠近中心），**镜像对称** |
| 定点 | Q1.15：32768 代表 1.0 |
| 奇数抽头和 | **恰好 16384 = 2^14**（配合中心 16384 → 总系数和 32768，直流增益 1.0） |
| 对称 | `o[i] == o[29-i]`，逐位精确 |

## 默认设计

`scripts/gen_hb_coef.py`：

- 理想半带 `h[n] = 0.5·sinc(0.5·(n-M))`，`M = (N-1)/2 = 30`
- 乘 Hamming 窗（窗在中心取 1，所以 `h[M]` 恰好是 0.5；在偶数偏移上乘的是 0，零点保持）
- 奇数抽头整体缩放，使 `sum(odd) = 0.5`；量化误差给离中心最近的那一对（成对修改，对称不变）

| 指标 | 值 |
|---|---|
| 抽头数 `N` | **61**（= 4q+1；中心下标才是偶数，偶相才只剩一个抽头） |
| 非零抽头 | 31（中心 + 30 个奇数） |
| 乘法器 | **15**（s03 的 FIR 是 24） |
| 中心抽头 | 16384（= 0.5） |
| 最大奇数抽头 | 10387（`o[14]` / `o[15]`） |
| 最外侧奇数抽头 | 30（`o[0]` / `o[29]`） |
| 通带 [0, 0.20] 纹波 | **0.0235 dB** |
| 阻带 [0.30, 0.5] 衰减 | **53.1 dB** |
| 半带互补性 | `A(f) + A(0.5-f) = 1`（结构性质，量化后仍严格成立） |
| 群延迟 | 30 个高速率采样 = 15 个输入样本 |

前 6 个：`30, -40, 59, -90, 134, -193`；中间一对：`10387, 10387`。

> **为什么表里的和是 16384 而不是 32768？**
> 因为中心那个 0.5（16384）不在表里。总系数和 = 表里 30 个数 + 16384 = 32768。
> 这一点被 `tb_hb_coef.v` 和生成器同时钉死。

## `hb5.mem` 是干什么的

5 抽头半带的唯一解：`[8192, 8192]`（奇数抽头各 0.25，中心 0.5）。
它对应**线性内插**：

```
y_o = (8192·x[n] + 8192·x[n-1]) >> 14 = (x[n] + x[n-1])/2
```

它给 TB 提供能一眼手算的边界用例：

- `x=1`、上一拍 0 → 和 = 8192 = **半个 LSB**：`ROUND=1` 得 1、`ROUND=0` 得 0
- `x=-1` → `ROUND=1` 得 0、`ROUND=0` 得 -1（算术右移向 −∞）
- `OW=8` 实例上满幅必须饱和到 +127/−128
- `IW=8` 实例验输入位宽

`tb_interp2.v` / `tb_decim2.v` 都用它。

## ⚠️ `$readmemh` 的路径坑（同 s01/s03）

路径是相对**仿真/综合进程的工作目录**，不是 `.v` 所在目录。读不到时**不报错**，
数组里全是 x。所以：

- 仿真：`scripts/sim.sh` 会传 `-DHB_COEFDIR="$ROOT/s04_resample/lut/"`（绝对路径）
- Vivado：Settings → Synthesis → Options → More Options 里写
  `-verilog_define HB_COEFDIR="D:/…/fpga-lab/s04_resample/lut/"`
  （开关和路径都要写，路径只出现一次，结尾带斜杠；详见 `constr/resample.xdc`）

RTL / TB 里的兜底：

```verilog
`ifndef HB_COEFDIR
  `define HB_COEFDIR "s04_resample/lut/"
`endif
initial $readmemh({`HB_COEFDIR, "hb_odd.mem"}, coef);
```

`tb_interp2.v` / `tb_decim2.v` / `tb_hb_coef.v` / `tb_resample_cascade.v` 都会先检查
"30 个值全部读入、没有 x"，所以真读不到时会在第一条断言就红，不会静默跑完。
