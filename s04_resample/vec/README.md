# `s04_resample/vec/` — 参考向量

> 由 `scripts/gen_resample_vec.py` 用 Python **任意精度整数**独立算出来，
> 和 RTL 的流水线结构无关。RTL 里再用 Verilog 写一遍同样的算术，
> 两边很可能犯同一个理解错误（s02 就是这么翻车的），所以这一层必须独立。

## 文件

| 文件 | 每行 | 用途 | TB |
|---|---|---|---|
| `interp_vec.txt` | `x  y_e  y_o`（3 个字） | 插值：1 个输入 → 两相输出 | `tb_interp2.v` |
| `decim_vec.txt` | `x_e  x_o  y`（3 个字） | 抽取：两相输入 → 1 个输出 | `tb_decim2.v` |
| `cascade_vec.txt` | `x  y`（2 个字） | 插值 → 抽取整条链 | `tb_resample_cascade.v` |

每个文件：**10 个字的文件头 + 2048 行数据**（4 个场景 × 512 样本）。

### 文件头（10 个 32 位字）

| 序号 | 内容 | 默认值 |
|---|---|---|
| 1 | 哨兵 `0xF04C0DE1` | —— |
| 2 | 场景数 | 4 |
| 3 | 每场景样本数 | 512 |
| 4 | 数据行数 | 2048 |
| 5 | IW | 12 |
| 6 | OW | 13（插值/抽取）、14（级联） |
| 7 | SHIFT | 14（插值）、15（抽取/级联） |
| 8 | ROUND | 1 |
| 9 | 系数校验和（32 位滚动和） | 见生成器 |
| 10 | LAT（输入到输出拍数） | 4（插值/抽取）、8（级联） |

TB 会先把这 10 个字和 RTL 参数逐项对一遍。**向量、系数、RTL 参数是成套的**，
只改一个不重新生成，要么失败得莫名其妙，要么"回放全绿但测的是旧滤波器"。

所有数值都是 **32 位补码的原始位模式**（负数写成 `FFFFFFFB` 那样），
TB 按各自位宽取低位。

## 四个场景

| # | 名字 | 输入 | 想抓什么 |
|---|---|---|---|
| 0 | impulse | 单点 2047 | 冲激响应 / 两相相位关系 |
| 1 | step | 直流 1000 | 直流增益（两相都比、逐位） |
| 2 | tones | 两个单音 | 通带/阻带；抽取场景专门放一个 0.40 的混叠音 |
| 3 | random | 满量程随机 | 位宽 / 符号扩展 / 舍入，覆盖面最广 |

单音频率：

- 插值：0.05 + 0.20（相对输入 Fs，都在通带内）
- 抽取：0.05 + **0.40**（相对 2Fs；0.40 落在半带阻带里，抽取后会混叠到 0.20 附近）

## 重新生成

```sh
make resample-vec                 # 写文件
make resample-vec-check           # 只校验（提交前用）
```

改了 `lut/hb_odd.mem`（比如换抽头数）**必须**重新生成向量，否则头里的校验和会对不上，
TB 第一条断言就红 —— 这是故意的。

## 三个模型的精确定义（对账时看这里）

设 `o[i]` 是 `hb_odd.mem` 的 30 个值，`K = 30`，`CW = 16`，算术右移是
**向 −∞ 取整**（Verilog 的 `>>>` / Python 的 `>>` 对负数都是这个行为）。

**插值**（`SHIFT = CW-2 = 14`）：

```
y_e[n] = x[n - K/2]                                     ← 纯延迟，没有乘法
y_o[n] = ( Σ_{i=0}^{K-1} o[i]·x[n-i] ) >>> 14           ← ×2 体现在少移一位
```

**抽取**（`SHIFT = CW-1 = 15`）：

```
y[n] = ( 2^14·x_e[n - K/2] + Σ_{i=0}^{K-1} o[i]·x_o[n-1-i] ) >>> 15
```

   注意 `x_o` 的下标是 `n-1-i`：奇相比偶相晚半个采样，窗口整体挪一格。
   少写这个 `-1`，输出会整体错半个采样（测试里表现为"形状对、数值错"）。

**级联**：先按插值模型算出 13 位的 `y_e / y_o`，再把它们当 `x_e / x_o`
喂给抽取模型（`IW = 13`、`OW = 14`）。中间的 13 位**不能截回 12**。

## 时序对齐（TB 里怎么比）

记号：第 k 个下降沿驱动的输入，对应第 k+LAT 个下降沿的输出。

| 文件 | LAT | 比对方式 |
|---|---|---|
| interp | 4 | 第 n 拍驱动 `x[n]`，用 `y_e/y_o` 比 `row[n-4]` |
| decim | 4 | 第 n 拍驱动 `x_e[n],x_o[n]`，用 `y` 比 `row[n-4]` |
| cascade | 8 | 第 n 拍驱动 `x[n]`，用 `y` 比 `row[n-8]` |

`y_e` 和 `y_o` 是**同一个输出时刻的两相**，必须用同一个 LAT，不能差一拍。

## 为什么级联的随机场景不能拿"≈ 延迟"当判据

`interp2 → decim2` 整体是一个**半带的平方**（低通），不是一根导线。
白噪声在 0.25·2Fs（= 输入奈奎斯特）附近有能量，正好落在半带截止点上，
本来就会被滤掉一部分 —— 实测随机场景和 `x[n-30]` 的最大偏差 274 LSB。

所以 `tb_resample_cascade.v` 里：

- **随机场景**只做**逐位向量回放**（这是更强的判据）
- "≈ 延迟 30 拍"只用**直流**和**通带单音**来断言（误差 ≤ 4 LSB）

这不是 bug，是"插值再抽取 ≠ 恒等"的物理事实。
