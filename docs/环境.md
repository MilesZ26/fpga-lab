## 本机（Mac，写代码 + 仿真）

| 项目 | 状态 |
|---|---|
| 系统 | macOS 27.0.1（Build 26A434）/ **Apple Silicon (arm64)** |
| 编译器 | `clang` / `make` / `flex` / `m4` / `curl` / `git` ✓ |
| Homebrew | ✅ 7.0.9，装在 `/opt/homebrew` |
| bison | ✅ **3.8.2**（源码编译在 `tools/bison/`） |
| iverilog | ✅ **13.0 (v13_0)**（源码编译在 `tools/iverilog/`） |
| 波形查看 | ✅ **Surfer** 0.7.0（Homebrew） |
| verilator | 未安装（可选） |
| gtkwave | 未安装（**不建议装**，见下） |
| 磁盘可用 | 约 20 GB |

> `tools/` 在 `.gitignore` 里，**工具链不进版本库**。换机器重新 `make setup` 即可。

### 装仿真器

```sh
make setup
```

`scripts/setup_tools.sh` 现在会：

1. 如果 `tools/iverilog/bin/iverilog` 已存在 → 直接跳过
2. 如果系统有 iverilog → 跳过
3. 有 Homebrew → `brew install icarus-verilog`
4. 都没有 → **源码编译进 `tools/`**（不写系统目录、不需要 sudo）
   - 先编译 **bison**（iverilog 的 `vhdlpp/parse.y` 用了 `%define api.pure`，
     而 **macOS 自带的 bison 是 2.3，2006 年的版本，报语法错误**）
   - 再编译 iverilog `v13_0`

**这一段是踩过坑的**：一开始只编 iverilog，挂在了 bison 上。见 `docs/进度.md` 的「已知坑」。

### 波形查看：用 Surfer，别用 GTKWave

**GTKWave 在 Homebrew 里已经被标记为 `disabled`**，上游也没提供可用的
macOS 二进制，`brew install gtkwave` 会失败。网上很多教程还在教这个。

改用 **Surfer**：Rust 写的，原生窗口，Apple Silicon 有现成二进制，不需要 X11。

```sh
brew install surfer
make wave VCD=build/tb_blinky.vcd     # make wave 会优先用 Surfer
```

### 关于 verilator

它的价值是更严格的 lint 和 SVA 断言支持 —— 属于"更好"，不是"必须"。
目前 `make lint` 用的是 iverilog，够用。想要它：`brew install verilator`。

## Windows 机器（只跑 Vivado）

| 项目 | 要求 |
|---|---|
| 内存 | 8 GB 勉强，**16 GB 舒服** |
| 磁盘空闲 | 几十 GB 起（**只装 7 series**）；全量安装要上百 GB |
| 显卡 | 不需要独立显卡 |
| 系统 | Windows 10/11 64-bit（x86-64） |
| Vivado | **ML Standard Edition（免费版）**，版本选择见 [上板指南](上板指南.md) |

**Vivado 没有 macOS 版本**，Xilinx 只发布 Windows 和 Linux x86-64 版本。
本机是 Apple Silicon，所以 Vivado 只能放在 Windows 机器上。

> ⏳ 这台机器的内存和磁盘空闲量**还没确认**，是 `docs/进度.md` 里的待决问题。
> 换新版本之前尤其要确认磁盘——安装体积是这里唯一的硬门槛。

### ⚠️ 版本不是随便选的

- **2020.2 及更早**：官方支持目标是 Windows 10，Win11 上属于不支持的组合
- **较新的版本**：才正式支持 Win11

但这个仓库对 Vivado 版本**几乎无要求**（不用厂商 IP、不打开教程工程），
所以选版本的判据只有两条：**官方支持你的系统** + **官方别太新**。
详见 [上板指南.md](上板指南.md) 的「开始之前」一节。

### 装完必须自检

```tcl
get_parts xc7a100t*
```

在 Vivado 的 Tcl Console 里跑。返回空 = 安装时漏勾了 7 series / Artix-7。
