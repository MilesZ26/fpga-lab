# 环境

## 本机（Mac，写代码 + 仿真）

| 项目 | 状态 |
|---|---|
| 系统 | macOS 27.0.1 / **Apple Silicon (arm64)** |
| 编译器 | `clang` / `make` / `flex` / `bison` / `perl` / `m4` / `curl` / `git` ✓ |
| Homebrew | **未安装** |
| iverilog | **未安装** ← 第一件要做的事 |
| verilator | 未安装（可选） |
| gtkwave | 未安装（可选，看波形用） |
| 磁盘可用 | ~22 GB |

### 装仿真器

```sh
make setup
```

`scripts/setup_tools.sh` 会：

1. 如果已经有 iverilog → 什么都不做
2. 如果有 Homebrew → `brew install icarus-verilog`
3. 都没有 → **把 iverilog 源码编译进本仓库 `tools/`**（不写系统目录、不需要 sudo）

第三条已验证可行：iverilog `v13_0` 的源码包自带 `configure`。

### 关于 verilator 和 gtkwave

- **verilator**：GitHub 的源码包**不含 `configure`**（需要 autoconf，本机没装），
  所以源码编译走不通。想要它只能先装 Homebrew。
  它的价值是更严格的 lint 和 SVA 断言支持 —— 属于"更好"，不是"必须"。
- **gtkwave**：看 `.vcd` 波形用。没有它时的退路是
  让 AI 写个 Python 脚本把 VCD 渲染成 PNG（然后用图片查看）。

## Windows 机器（只跑 Vivado）

| 项目 | 要求 |
|---|---|
| 内存 | 8 GB 勉强，**16 GB 舒服** |
| 磁盘空闲 | **≥ 50 GB**（Vivado 本体 + 工程中间文件） |
| 显卡 | 不需要独立显卡 |
| 系统 | Windows 10/11 64-bit（x86-64） |

**Vivado 没有 macOS 版本**，Xilinx 只发布 Windows 和 Linux x86-64 版本。
本机是 Apple Silicon，所以 Vivado 只能放在 Windows 机器上。
