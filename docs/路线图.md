## 主线：Stage 2 基带数据通路

求职技术重建的方向。目标是重建 5G 基带链路的 FPGA 实现手感，
最终做出**能给出误差对比**的 DUC / DDC。

| 阶段 | 内容 | 核心能力 |
|---|---|---|
| **2.1** | **NCO / DDS**：相位累加器 + 查表 | 参数化设计、定点数、量化误差 |
| **2.2** | 复数混频 | 定点乘法、位宽增长、截位与舍入 |
| **2.3** | **FIR 滤波器** | 卷积结构选择、系数来源、对称优化、位宽 |
| **2.4** | **插值 / 抽取** | 多速率处理、CIC / 半带 / 多相滤波 |
| **2.5** | **DUC 集成** | 链路联调、增益分配、时序收敛 |
| **2.6** | **DDC** | 逆过程；滤波器设计可与 DUC 复用 |

**里程碑 M1**：DUC 链路跑通 + 波形 + 误差对比（参考模型用 Python 或 MATLAB）。

**不写死日期** —— 按能力达成算。**2.3 和 2.4 是真正的硬骨头**，
NCO 和混频相对快，别用前两个的速度去估算后两个。

## 支线：需要时插入，但**不许挡在主线的路上**

| 内容 | 什么时候需要 | 为什么值得做 |
|---|---|---|
| **CDC / 异步 FIFO** | 多速率处理里必然出现跨时钟域 | 面试高频；`report_cdc` 干净是硬指标 |
| **UART** | 需要一个调试通道 | 面试高频；很多时候比 ILA 省事 |
| **AXI4-Lite / AXI4-Stream** | 以后要做 SoC 集成、挂到 Zynq PS 上 | FPGA 岗位的硬通货 |

## 暂缓：与目标无关，先不碰

- **SPI / I2C** —— 传感器 / EEPROM 类外设接口，跟基带链路不搭
- **DDR / MIG** —— 现在没有带宽问题，做了也是玩具
- **流水灯 / PWM / 按键消抖** —— 纯入门练习（目录保留在 `s01_*`）

## 每个阶段的通用验收方式

1. RTL + testbench 齐全
2. `make sim` 全绿、`make lint` 无警告
3. **改坏一行 RTL，对应的测试必须变红**（否则那条断言是摆设）
4. （能上板的）Vivado 综合 + 时序收敛
5. 更新 `docs/进度.md`
