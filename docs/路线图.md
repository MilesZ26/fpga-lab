## Stage 1~6 — 基带数据通路

| Stage | 内容 | 核心能力 |
|---|---|---|
| **1** | **NCO / DDS**：相位累加器 + 查表 | 参数化设计、定点数、量化误差 |
| **2** | 复数混频 | 定点乘法、位宽增长、截位与舍入 |
| **3** | **FIR 滤波器** | 卷积结构、系数来源、对称优化、位宽 |
| **4** | **插值 / 抽取** | 多速率处理、CIC / 半带 / 多相滤波 |
| **5** | **DUC 集成**：FIR 成型 → 混频 → 2× 插值 | 链路联调、增益分配、NCO 相位对齐 |
| **6** | **DDC**：2× 抽取 → 下变频 → 基带 FIR | 逆过程；回环逐位对账、LO 延迟标定 |

## 每个 stage 的通用验收方式

1. RTL + testbench 齐全
2. `make sim` 全绿、`make lint` 无警告
3. **改坏一行 RTL，对应的测试必须变红**（否则那条断言是摆设）
4. （能上板的）Vivado 综合 + 时序收敛
5. 更新 `docs/进度.md`

## 关于两台机器

**只有真的要上板时才需要 Windows**（Vivado 没有 macOS 版）。
仿真验收在 Mac 上能全部完成。

Mac ↔ Windows 之间**只用 git 传文件，不要用网盘**：网盘没有历史、没有 diff、
冲突时静默覆盖，而且会去同步 `*.runs/`、`*.cache/` 这些动辄几 GB、
每次综合都在变的中间产物。
