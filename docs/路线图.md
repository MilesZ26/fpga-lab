# 路线图

方向：**通用数字设计 + 接口**（UART / SPI / I2C / AXI / DDR）
平台：Xilinx Artix-7 / Zynq（Vivado 在 Windows 机器上跑）

**当前进度：Stage 0 + Stage 1**

| 阶段 | 内容 | 核心能力 | 验收标准 |
|---|---|---|---|
| **0** | 验证闭环 + 点亮 LED | XDC 约束、一键仿真、非工程模式综合 | `make sim` / Vivado 综合 / 上板三条链路都通 |
| **1** | 流水灯 → PWM → 按键消抖 → **UART 回环** | 时序逻辑、参数化、状态机、波特率 | UART 收发回环正确；波特率误差边界验证 |
| **2** | **SPI master/slave、I2C master** | `inout` 双向线、开漏上拉、时钟极性与相位 | 真的从 EEPROM 读到 ID / 从传感器读到数据 |
| **3** | 同步/异步 FIFO、双口 RAM、同步器、握手 | **跨时钟域 CDC** | 异步 FIFO 全边界测试通过；`report_cdc` 无 critical |
| **4** | **AXI4-Lite → AXI4-Stream → AXI4(full)** | 把模块挂上标准总线、IP 封装 | PS 能正确读写自定义寄存器；AXI-Stream 经 DMA 跑通 |
| **5** | MIG / Zynq HP 端口、AXI4 突发 | outstanding、带宽计算 | 实测 DDR 带宽达到理论值的可信百分比 |
| **6** | 时序收敛、SVA、覆盖率、CDC 约束 | 工程化交付 | WNS ≥ 0、`report_cdc` 干净、覆盖率达标 |

## 重心在哪

前两个阶段是**练手**，建议**刻意做快**，别在流水灯上雕花。

真正长本事的是 **Stage 3 和 Stage 4**。接口代码写起来不难，
"看起来能跑但偶发挂死"几乎都出在 **CDC** 和 **总线握手协议**上：

- VALID/READY 反压处理
- burst 边界
- outstanding 溢出
- 复位域不一致

## 每个阶段的通用验收方式

1. RTL + testbench 齐全
2. `make sim` 全绿
3. （能上板的）Vivado 综合时序收敛
4. `docs/进度.md` 更新

## 关于 Windows 机器

Stage 0 和 Stage 1 的验收标准**全是仿真**，不需要 Windows 机器。
上板是加分项。可以先把基本功打扎实，Vivado 那条路等真要上板时再打通。
