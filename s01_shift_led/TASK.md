# Stage 1.1 — 参数化流水灯

## 目标

一个参数化、可双向的流水灯。

## 要求

| 参数 / 端口 | 含义 |
|---|---|
| `WIDTH` | LED 位宽，例如 4 / 8 |
| `STEP_HZ` | 移位频率（每秒移动几位） |
| `CLK_HZ` | 输入时钟频率 |
| `dir` | 方向输入：0 = 向左，1 = 向右 |
| `led[WIDTH-1:0]` | 输出 |
| `rst_n` | 复位后**只有最右边一位亮**（`led = 1`） |

## 验收标准

- [ ] 复位后 `led === 1`（最右一位亮）
- [ ] 每经过 `CLK_HZ / STEP_HZ` 个时钟左移一位
- [ ] 最高位移出后从最低位循环回来（**循环移位**，不是补零）
- [ ] `dir` 改变方向后，**下一次**移位才生效（不要把当前这次也改了）
- [ ] `dir` 也要先过 `rtl/common/edge_detect.v` 或 `sync_2ff`（如果是按键）
- [ ] `make sim` 全绿，`make lint` 无警告

## 提示

- 循环左移一位：`led <= {led[WIDTH-2:0], led[WIDTH-1]};`
- 循环右移一位：`led <= {led[0], led[WIDTH-1:1]};`
- **不要用 case 把每种图案硬编码一遍** —— 那没学到东西，而且 WIDTH 一改就废。
- 分频器的写法可以直接借 `s00_blinky/rtl/blinky.v` 的计数器结构，
  但注意这里是"每 N 拍产生一个 1 拍脉冲"，不是"每 N 拍翻转一次"。
