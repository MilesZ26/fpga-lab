## 目标

```
                               ┌──────────────┐
  i_in ──► FIR_I ──► 13b ──┐   │              │
  (12b)      │              ├──►│ mixer CONJ=0 │──► 14b ──► interp2_I ──► i_e / i_o (15b)
             │              │   │  NCO @ f_lo  │                    │
  q_in ──► FIR_Q ──► 13b ──┘   │              │──► 14b ──► interp2_Q ──► q_e / q_o (15b)
  (12b)                         └──────────────┘
```

| 参数 | 含义 | 默认 |
|---|---|---|
| `IW` | 输入符号位宽（补码） | 12 |
| `CW` / `N_FIR` | FIR 系数位宽 / 抽头数 | 16 / 47 |
| `N_HB` | 半带总抽头数（4q+1） | 61 |
| `AW` / `PHASE_W` / `LUT_AW` | NCO 幅度 / 相位 / 查表地址位宽 | 12 / 32 / 12 |
| `FREQ_HZ` | 本振频率（低 IF） | 2.5 MHz = **0.05 Fs** |
| `OW_FIR` / `OW_MIX` / `OW_INT` | 各级输出位宽 | 13 / 14 / 15 |
| `SHIFT_FIR` / `SHIFT_MIX` / `SHIFT_INT` | 各级右移 | 15 / 11 / 14 |
| `LO_DLY` | 本振相对 FIR 输出的延迟 | **4** |

## 写之前要决定的四件事（已决定 + 理由）

### ① 为什么 FIR 在混频**之前**（旧文档的猜测在这里被改正）

s03 的 TASK 里写过"DUC 里 FIR 在混频之后、插值之前"。那是**没集成时的猜测**。
真接起来，有两个理由要求把 FIR 放到混频之前：

1. **成型滤波必须在基带做。** 混频之后再低通，滤波器响应是 `H(f)` 而不是
   `H(f-f_lo)` —— 它按低通的过渡带去削 f_lo 附近的信号，而不是按设计时
   看到的那条平坦通带。f_lo 取得很低（0.05 Fs）时"看起来还行"，
   换一个 IF 就露馅。
2. **标准 DUC 的顺序就是：成型（基带）→ 上变频 → 插值。** 插值半带是低通，
   正好把混频后的镜像/高频分量挡在 DAC 之前。本设计 f_lo=0.05 Fs、
   测试单音 0.01 Fs，混频后落在 0.06 Fs，远在半带通带 [0, 0.4 Fs] 之内。

代价：混频器工作在 Fs（不是 2Fs），所以只要**一个**复数混频器（4 个乘法器），
不需要在 2Fs 上再做一次。这是有意的取舍；约束是
**f_lo 必须落在 FIR 通带内，且 f_lo + 信号带宽 < 0.10 Fs**。

> 这个改正也同步写进了 `docs/进度.md` 和 `docs/学习备忘.md` 第 17 节。
> 旧 s03/s04 TASK 里那两句"混频之后/之前"的说法以 s05 为准。

### ② 增益预算：每一级为什么是这个位宽

| 级 | 输入 | 输出 | 增益 | 峰值（满幅单音） | 余量 |
|---|---|---|---|---|---|
| 符号 | — | 12b | 1.0 | ±2047 | — |
| FIR（Q1.15，和=32768） | 12b | **13b** | 1.0 | ±2047 | 1 位（±4095） |
| 混频（SHIFT=11） | 13b | **14b** | 2047/2048 ≈ 1.0 | 单路 ±4092（I/Q 同时满幅） | 刚好（±8191） |
| 插值（SHIFT=14） | 14b | **15b** | 1.0（×2 补偿 / 半带 0.5） | ±2047 | 很大（±16383） |

- **混频的 14 位是"刚好够"**：`2047·2047·2 >> 11 = 4092`，再加舍入常数也不会
  超过 14 位正上界 8191。如果以后换增益 > 1 的成型滤波器，这里要重新算。
- **插值的 15 位是留给以后换滤波器的**：当前信号只用到 ±2047，15 位有 3 位余量。
  这也是为什么"把 interp 的 IW 从 14 改成 13"在满幅单音下**测不出来**：
  第 14 位是符号扩展/余量位，不是有效位。真正改坏的是 **SHIFT**（增益）——
  见下面的反向验证 S2。
- **先全精度算完，最后才截**：每个模块内部都保留了 `SUM_W` / `FINAL_W`，
  级联时**不要**在模块之间再截一次。s04 的"interp 出 13 位、decim 的 IW 必须也是 13"
  就是同一类约束。

### ③ 位宽链（连线时照这张表抄）

```
i_in/q_in 12
   │ FIR (IW=12, OW=13, SHIFT=15)
   ▼
fir_i/fir_q 13
   │ mixer (IW=13, AW=12, OW=14, SHIFT=11, CONJ=0)
   ▼
mix_i/mix_q 14
   │ interp2 (IW=14, CW=16, N=61, OW=15, SHIFT=14)
   ▼
i_e/i_o/q_e/q_o 15   ← 这就是 s06 的输入位宽
```

> ⚠️ **不要**把 `interp2` 的 `IW` 写成 13 或 12：那会把 mix 的 14 位结果截掉，
> 虽然满幅单音下可能看不出（见上），但随机/多音信号会慢慢累积误差。
> 正确做法是让每一级的 `OW` 等于下一级的 `IW`，并把这条写成参数表达式。

### ④ 本振相位：LO_DLY = 4（以及为什么不能"看起来对"）

混频器必须用**同一时刻进入它的那个样本**所对应的本振相位。
FIR 有 4 拍流水、NCO 自己有 1 拍输出寄存器，所以本振不能直接接：

- 直接接 → `y[n]` 乘上 `lo[n+3]` 附近的值；
- 结果：**频率完全正确，但整条链的相位整体旋转一个常数**；
- 用 ILA 看频率/幅度几乎看不出来，只有和 Python 向量逐位对才会红。

`LO_DLY` 的精确值不要手推（Verilog 的 always 块读的是时钟沿**之前**的值，
"模块延迟 4 拍"和"链路上实际晚几拍"差一个 handoff）。本仓库的做法是：
**用逐位向量标定**，标定结果写进 `scripts/gen_duc_ddc_vec.py` 的
`LO_DLY_DUC = 4` 和 `tb_duc_core.v` 的 `LAT=9`。

## 延迟（这是集成时第二个容易错的地方）

| 量 | 值 | 组成 |
|---|---|---|
| DUC 输入 → 输出 | **9 拍** | FIR 4 + mixer 1 + interp 4 |
| `i_e` 的端到端群延迟 | +15 个输入样本 | 半带偶相 = `dly[15]`；再加 3 级对齐寄存器 |
| `i_o` 的端到端 | 与 `i_e` 同一输出下标 | 30 个奇数抽头，峰值在 k=14/15 |

TB 的约定：下降沿驱动输入，同一个下降沿读输出；第 k 个输入对应第 **k+9** 个输出。
**别把"流水 9 拍"和"半带群延迟 15"混成一个数** —— 前者是拍数，后者是样本数。

### 反向验证（仓库规矩 3）：4 处变红 + 1 处"不该红"的发现

| 改坏的地方 | 实际反应 |
|---|---|
| S1 `duc_core` 混频 `CONJ(0)` → `CONJ(1)`（把上变频改成下变频） | **4 条 FAIL**：4 个场景的向量回放全红（ee=83 / 986 / 1936 / 1954） |
| S2 `interp2` 的 `IW` 从 `OW_MIX`(14) → `OW_MIX-1`(13) | **0 条 FAIL** —— ⚠️ 这**不是**"测试没覆盖"：满幅单音峰值 2039 本来就在 13 位范围内，截掉的是余量位。真正的增益错见 S2b |
| S2b `interp2` 的 `SHIFT` 从 14 → 15（幅度减半） | **6 条 FAIL**：4 个向量场景 + 小实例的 `i_o`（1000 → 500） |
| S3 `duc_core` 本振 `sin_dly[0] <= lo_sin` → `lo_cos`（sin/cos 接反） | **7 条 FAIL**：复位后的"输出非零"检查 + 4 个向量场景 + 小实例 |
| S4 `duc_top` 的 `led` 全接 0 | **1 条 FAIL**：LED 心跳不翻转 |

> **S2 是这一轮最值得记的发现**：位宽实验不一定"改了就该红"。
> 多出来的那一位可能只是余量，不是有效位；要证明测试覆盖了增益，
> 得改 `SHIFT`（S2b），而不是改位宽。写进 [学习备忘](../docs/学习备忘.md) 第 17 节。

## 这个 stage 的边界 / 留给后面

- **只做 2× 插值**：4× 要级联两级半带；截止固定 1/4 采样率，不支持任意 L/M。
- **f_lo 是低 IF（0.05 Fs）**：FIR 在混频之前，所以 f_lo 必须落在 FIR 通带内；
  要搬到更高的 IF，得把插值放到混频之后（或在 2Fs 上再做一次混频），
  那是另一个结构，不在本 stage 里。
- **`duc_top` 是实验台**：测试单音 NCO 不是 DUC 的一部分；
  真正发射时要换成成型滤波之后的符号。
- **2:1 并串只在仿真里验过**：板上没有 DAC，ILA 只能看 clk 上升沿的并行四相；
  这是有意的取舍，不是漏做。
- **资源预估**：2 个 FIR（约 2×21 DSP）+ 1 个混频（4）+ 2 个 interp2（2×15）
  ≈ **76 DSP**（以综合报告为准）；比 s04 的 30 DSP 翻倍多，但 100T 有 240 个。
