### 56 条 DRC 的构成

| 规则 | 条数 | 含义 |
|---|---|---|
| REQP-1839（RAMB36 异步控制脚） | 20 | ⇐ **撞到规则上限**，真实数量 ≥ 20 |
| REQP-1840（RAMB18 异步控制脚） | 20 | ⇐ 同样撞上限 |
| DPIP-1（输入流水） | 8 | ILA 探针没有输入流水级 |
| DPOP-1 / DPOP-2（输出流水） | 2 + 2 | ILA 输出寄存器流水 |
| CFGBVS-1 | 1 | 没设配置电压，与功能无关 |
| CHECK-3 | 2 | 上面两条撞了上限的标记 |

> **"REQP 是不是比 s01 翻倍了？"** —— 有**两个** NCO 在驱动 BRAM 地址脚，
> 按理应该翻倍，但因为 20 条是**规则上限**，报告里两边都是 20，**看不出来**。
> 想知道真实数量得 `set_property max_violations` 放开上限重跑 `report_drc`。
> 这不影响功能（见 `docs/学习备忘.md` 第 8 节）。

## 板级波形判据（2026-10-17 实测，**两版都跑了**）

### ① 下变频：`CONJ = 1`（仓库里的默认值）

| 检查 | 实测 | 判据 |
|---|---|---|
| `i_out` 周期 | 8192 点窗口里 **约 8 个周期** → 1000 点/周期 = 50 kHz（20 µs） | ≈ 1000 点 ✅ |
| `sig_sin` 周期 | 约 **41 个周期** → 200 点/周期 = 250 kHz（4 µs） | ≈ 200 点 ✅ |
| 比例 | **5 : 1** | `FREQ_IN / (FREQ_IN − FREQ_LO)` = 250/50 = 5 ✅ |
| LED | 半亮（50 kHz 人眼跟不上） | 与 `mixer.xdc` 注释一致 ✅ |

### ② 上变频：`CONJ = 0`（临时改参数重综合的一版，跑完已改回 1）

| 检查 | 实测 | 判据 |
|---|---|---|
| `i_out` 周期 | 窗口里 **约 73 个周期** → 111 点/周期 = **450 kHz**（2.22 µs） | 450 kHz / 50 MHz = 111.1 点 ✅ |
| `sig_sin` 周期 | 仍应是 **41 个周期**（200 点/周期，250 kHz）—— 输入没变 | ≈ 200 点 |
| 比例 | 约 **1.8 : 1** | `FREQ_IN/(FREQ_IN + FREQ_LO)` = 250/450 ≈ 0.56 ✅ |

> **结论：和频和差频都搬对了。** 上变频 250 + 200 = 450 kHz、下变频 250 − 200 = 50 kHz，
> 两版 ILA 都验证了 —— 这才是 `CONJ` 这条开关真正被证明过的样子。
> 和频那版的 i_out 比差频密 9 倍（73 个周期 vs 8 个），窗口里也能看清。

> ⚠️ 区分两个"默认值"：`mixer.v` 自己的默认是 `CONJ = 0`（上变频，DUC 用），
> **`mixer_top.v` 的默认是 `CONJ = 1`**（下变频，差频 50 kHz 在窗口里正好 8 个周期，好看好数）。
> **仓库里保持 1**；和频那一版是把顶层参数临时改 0 综合出来的。
